# Чистый путь

Сайт компании грузоперевозок из Китая в Россию «Чистый путь». Один файл `index.html`, без сборки.

Страницы переключаются по адресу после `#`: `#home`, `#services`, `#prices`, `#cases`, `#about`, `#contacts`, `#privacy`.

Что нужно заменить перед запуском:
- телефон, почту, ссылку на Telegram и реквизиты ООО (в контактах и в политике конфиденциальности);
- примерные отзывы и кейсы на настоящие;
- обработчик формы заявки (сейчас заявка никуда не отправляется).

Публикация: GitHub Pages, ветка `main`, папка `/` (root).

Предыдущая версия репозитория (сайт HayOS) сохранена в истории коммитов.
