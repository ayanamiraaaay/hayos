# Чистый путь

Сайт компании грузоперевозок из Китая в Россию «Чистый путь». Статический сайт без фреймворков: 19 HTML-страниц, один файл стилей и один скрипт. Публикуется через GitHub Pages (ветка `main`, корень).

## Как устроен репозиторий

```
src/
  config.json      ← все данные компании: телефон, реквизиты, адреса, настройки
  pages/*.html     ← содержимое страниц (без шапки и подвала)
  style.css        ← стили всех страниц
  app.js           ← скрипт: меню, заявки, калькулятор, отслеживание, cookie
build.py           ← собирает страницы в корень репозитория
worker/            ← сервер для отправки заявок в Telegram (Cloudflare Worker)
*.html, assets/    ← готовый сайт (создаётся сборкой, вручную не править)
```

Шапка, подвал, форма заявки и страницы городов (Казань, Екатеринбург, Новосибирск) описаны в `build.py`.

## Как поменять данные и пересобрать

1. Отредактируйте `src/config.json` или нужный файл в `src/pages/`.
2. Запустите `python3 build.py` (нужен Python 3.8+, для картинки превью — Pillow).
3. Закоммитьте изменения: GitHub Pages обновит сайт за 1–2 минуты.

## Что заменить перед запуском

- `src/config.json`: телефон, Telegram, MAX, WhatsApp, WeChat, почта, ИНН, ОГРН, адреса складов в Китае (сейчас там `[warehouse address]`), ссылки на отзывы в Яндекс Картах и 2ГИС.
- Отзывы, кейсы и блок «Что можно проверить» на странице «О компании» — примерные. Замените на настоящие и поставьте `"showSampleBadges": false`, чтобы убрать метки «Пример».
- Цифры (14 200+ партий, 0,3% претензий, 40 сотрудников) и тарифы — тоже примерные. Ставки калькулятора лежат в `src/app.js` в объектах `MODES`, `ORIGINS`, `DESTS`, `CATS`.
- Расписание отправок — объект `SCHEDULE` в `src/app.js`.

## Подключение заявок в Telegram

Токен бота нельзя хранить в коде сайта: его увидит любой посетитель. Поэтому заявки идут через небольшой сервер.

1. Разверните `worker/lead-to-telegram.js` на Cloudflare Workers (инструкция в начале файла).
2. Впишите адрес воркера в `src/config.json` → `leadEndpoint` и пересоберите сайт.

Пока `leadEndpoint` пустой, формы работают в демо-режиме и честно пишут, что заявка никуда не отправлена.

## Отслеживание грузов

Страница `tracking.html` показывает демо-груз `ЧП-48213`. Для настоящих данных укажите в `trackEndpoint` адрес, который по запросу `?n=ЧП-12345` возвращает JSON:

```json
{"number":"ЧП-12345","status":"В пути","eta":"2026-11-20","cargo":"Одежда, 38 мест, 1 240 кг",
 "events":[["Принят на складе в Гуанчжоу","Фото 38 мест","2026-11-01","done"],
           ["Склад в Москве","","2026-11-20",""]]}
```

Последнее поле события: `done` — пройдено, `now` — текущий этап, пусто — впереди.

## Яндекс Метрика

Впишите номер счётчика в `metrikaId`. Метрика загрузится только после того, как посетитель нажмёт «Принять» в баннере о cookie. Баннер появляется, только когда счётчик указан.
